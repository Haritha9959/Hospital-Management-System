# Hospital Management System (Java)

This project is a simple Hospital Management System developed using Java.

## Features
- Add Patient
- View Patients
- Add Doctor
- View Doctors
- Book Appointment

## Technologies Used
- Java
- OOP Concepts

## Files
- Main.java
- Patient.java
- Doctor.java
- Appointment.java
- HospitalManagement.java

## How to Run

Compile:

javac Main.java

Run:

java Main
